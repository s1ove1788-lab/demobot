# Демо-бот «Автосервис» для MAX

Рабочий бот записи для вымышленного автосервиса «ТурбоГараж». Ссылку на него вы отправляете
владельцам автосервисов и детейлингов: они записываются как клиент и сразу видят, как заявка
приходит владельцу.

## Что умеет
- Запись: услуга → марка авто → день → свободное время → телефон → подтверждение
- Прайс, адрес и часы работы, «Вопрос мастеру», «Мои записи» с отменой
- Владелец одной кнопкой: подтвердить / отклонить / «Машина готова»
- Напоминание клиенту за 2 часа до визита, оценка 1–5⭐ и отзыв после визита
- Защита от двойной записи: на один час не больше 2 машин (меняется в `SLOT_CAPACITY`)
- **Демо-режим:** клиент получает копию карточки «так видит владелец» и может понажимать кнопки
- **Вам приходит уведомление о каждом, кто открыл демо** — сразу видно, кому написать
- Команды для вас: `/today`, `/tomorrow`, `/stats`

## Запуск на сервере (там же, где ваши боты)
1. Создайте нового бота на business.max.ru и получите токен.
2. Скопируйте папку на сервер, затем:
   ```bash
   cd autoservice-demo
   pip install -r requirements.txt
   cp .env.example .env      # впишите MAX_TOKEN
   python3 bot.py
   ```
3. Напишите боту — он пришлёт ваш ID. Впишите его в `ADMIN_IDS` в `.env` и перезапустите.

Чтобы бот работал постоянно, запустите его как службу (как ваши остальные боты), например через
`systemd` или `screen`.

## Ссылки с меткой источника
Добавляйте к ссылке на бота `?start=avito`, `?start=reels`, `?start=chat` — в уведомлении
«новый человек открыл демо» будет видно, откуда он пришёл.

## Как переделать под реального клиента
Меняется только блок «Настройки бизнеса» в начале `bot.py`:
- `BUSINESS` — название, адрес, часы, телефон;
- `CATEGORIES` — услуги и цены;
- `WORK_DAYS`, `SLOT_HOURS`, `SLOT_CAPACITY` — график и сколько боксов.

Затем в `.env` ставите `DEMO_MODE=0` и в `ADMIN_IDS` — ID владельца сервиса (и свой, если ведёте поддержку).
